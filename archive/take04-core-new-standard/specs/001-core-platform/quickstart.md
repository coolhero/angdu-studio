# Quickstart: Core Platform

**Feature**: F001-core-platform
**Date**: 2026-03-04

---

## Prerequisites

- Node.js 20+ (LTS)
- pnpm 9+ (package manager)
- Git

## Setup

```bash
# Clone and install
git clone <repository-url> angdu-studio
cd angdu-studio
pnpm install

# Development mode
pnpm dev

# Build for production
pnpm build
```

## Key Integration Points

### 1. IPC Channel Usage (for downstream Features)

All IPC communication uses the shared `IpcChannel` enum:

```typescript
// packages/shared/IpcChannel.ts
import { IpcChannel } from '@shared/IpcChannel'

// Main process handler registration
ipcMain.handle(IpcChannel.Config_Get, async (_, { key }) => {
  return configManager.get(key)
})

// Preload API (wraps ipcRenderer.invoke)
const config = {
  get: (key: ConfigKeys) => ipcRenderer.invoke(IpcChannel.Config_Get, { key }),
  set: (key: ConfigKeys, value: any) => ipcRenderer.invoke(IpcChannel.Config_Set, { key, value }),
}

// Renderer usage via hook
const theme = useConfig(ConfigKeys.Theme)
```

### 2. Adding a New IPC Channel

1. Add enum member to `packages/shared/IpcChannel.ts`:
   ```typescript
   Provider_List = 'provider:list',
   ```
2. Add handler in `src/main/ipc/<domain>.ipc.ts`
3. Add preload wrapper in `src/preload/api/<domain>.ts`
4. Expose via `window.api.<domain>.<method>()`

### 3. Adding a Dexie Table (for F002+)

```typescript
// src/renderer/src/lib/db.ts
import Dexie from 'dexie'

class AppDatabase extends Dexie {
  constructor() {
    super('cherry-studio', { chromeTransactionDurability: 'strict' })

    // v1: F001 tables
    this.version(1).stores({
      files: 'id, name, type, created_at',
    })

    // v2: F005 tables (added by F005 implementation)
    this.version(2).stores({
      files: 'id, name, type, created_at',
      topics: '&id',
      message_blocks: 'id, messageId',
    })
  }
}
```

### 4. Adding a Zustand Store

```typescript
// src/renderer/src/stores/useNewStore.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'
import { broadcastSync } from './middleware/broadcastSync'

interface NewState {
  value: string
  setValue: (v: string) => void
}

export const useNewStore = create<NewState>()(
  broadcastSync(
    persist(
      (set) => ({
        value: '',
        setValue: (v) => set({ value: v }),
      }),
      { name: 'new-store' }
    ),
    { channel: 'new-store-sync' }
  )
)
```

### 5. Adding a Route (TanStack Router)

Create a file in `src/renderer/src/routes/`:

```typescript
// src/renderer/src/routes/settings.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/settings')({
  component: SettingsPage,
})

function SettingsPage() {
  return <div>Settings</div>
}
```

Route tree is auto-generated by TanStack Router.

### 6. Theme Integration

Themes use CSS variables. To add a themed component:

```css
/* Use CSS variables for colors */
.my-component {
  background: var(--background);
  color: var(--foreground);
  border-color: var(--border);
}
```

Dark mode is toggled via `class="dark"` on `<html>`. Tailwind CSS 4 handles the rest automatically.

### 7. i18n Integration

```typescript
// Add keys to src/renderer/src/i18n/locales/en-US.json
{
  "settings.title": "Settings",
  "settings.theme": "Theme"
}

// Use in React components
import { useTranslation } from 'react-i18next'

function MyComponent() {
  const { t } = useTranslation()
  return <h1>{t('settings.title')}</h1>
}
```
