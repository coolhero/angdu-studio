# Chat Conversation — Spec Draft

> `/reverse-spec` Phase 4에서 자동 생성. `/speckit.specify`의 시드 입력으로 사용.

## Feature 설명

앱의 핵심 Feature로, 채팅 메인 페이지(사이드바 + 메시지 영역 + InputBar), 메시지 블록 기반 렌더링(마크다운, 코드, 이미지, 사고 과정, 도구 호출 등), Vercel AI SDK 기반 스트리밍 응답, 토픽/어시스턴트 관리, TipTap 리치 에디터 기반 InputBar를 포함하는 최대 규모 Feature이다.

## 성공 기준 (Success Criteria)

### Happy Path
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-001 | 메시지 전송 + 스트리밍 | 텍스트 입력 → Enter | 사용자 메시지 표시 → AI 스트리밍 응답이 실시간으로 렌더링 |
| SC-002 | 토픽 자동 생성 | 새 어시스턴트에서 첫 메시지 전송 | 자동으로 토픽 생성, 토픽 목록에 추가, 이름 자동 설정 |
| SC-003 | 어시스턴트 전환 | 다른 어시스턴트 클릭 | 해당 어시스턴트의 토픽 로드, 채팅 영역 갱신 |
| SC-004 | 파일 첨부 | 이미지 드래그 앤 드롭 | 미리보기 표시, 메시지와 함께 전송 |
| SC-005 | 메시지 재생성 | 재생성 버튼 클릭 | 마지막 AI 응답 삭제 → 새 응답 스트리밍 |
| SC-006 | 채팅 내 검색 | Ctrl+F → 검색어 입력 | 매칭 메시지 하이라이트, 이전/다음 네비게이션 |

### Error Paths
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-E01 | API 호출 실패 | 잘못된 API Key | ErrorBlock 표시, 에러 메시지 포함 |
| SC-E02 | 스트리밍 중 네트워크 단절 | 응답 수신 중 연결 끊김 | 현재까지 수신된 응답 유지, 에러 메시지 표시 |
| SC-E03 | 빈 메시지 전송 | 텍스트 없이 Enter | 전송 무시 (파일 첨부만 있으면 전송 가능) |
