## 1. Runtime Exploration Results

**Screens**: Settings sub-pages (Backup, API Server, Web Search), Selection toolbar (floating window)

### Backup/Sync (Settings -> Data)
- WebDAV sync: host, user, pass, path config, test connection, backup/restore, file listing
- S3 sync: endpoint, region, bucket, accessKeyId, secretAccessKey, root path config, test connection, backup/restore
- Local backup: backup to local directory, list/restore/delete backups
- LAN transfer: create backup for LAN transfer, delete temp backup
- Backup progress: real-time progress events via IPC
- All sync types: last sync time, syncing state, error state

### API Server (Settings -> API Server)
- Express-based REST API server running on configurable host:port
- Routes: /chat (completions), /models (list), /messages, /agents, /mcp
- Server controls: Start, Stop, Restart, status indicator
- Config: port (default varies), host binding
- Timeouts: 5-minute request, 60-second keepalive

### Web Search (Settings -> Web Search)
- Search providers: configurable list (local-bing default, plus many others)
- Provider config: per-provider API keys and settings
- Global settings: searchWithTime, maxResults, excludeDomains
- Subscribe sources: URL-based provider subscription with blacklist
- Compression: none, cutoff (char/token limit), RAG (embedding-based)
- Compression model config: embedding model, dimensions, document count, rerank model

### Selection Toolbar
- Floating toolbar that appears on text selection in any application
- Trigger modes: configurable (e.g., on selection, on hotkey)
- Filter modes: whitelist/blacklist for applications
- Actions: AI-powered text processing (translate, summarize, explain, etc.)
- Window management: pin, minimize, close, resize, follow selection
- Separate BrowserWindow with custom positioning

### Auto-Update
- App update checker and installer
- Update notifications with changelog
- Auto-download and install flow

### Power Monitoring
- System power status monitoring (battery, charging, AC power)

## 14. For /speckit.analyze

- BackupManager caches WebDAV/S3 clients and compares connection configs to avoid unnecessary reconnects
- Backup restore calls closeAllDataConnections() to release file handles before extraction
- Windows permission handling uses both fs.chmod and exec('attrib -R') as defense in depth
- API server uses 5-minute request timeout -- longer than typical for streaming chat responses
- Selection toolbar is 54KB of code (SelectionService.ts) -- the most complex single service
- Web search defaultProvider is deprecated (user selects per-query now) but kept for backward compat
- Compression config has three tiers: none (pass-through), cutoff (truncate), RAG (embed + search)
- Backup temp dir uses app.getPath('temp') -- cleaned up on next backup or explicit delete
