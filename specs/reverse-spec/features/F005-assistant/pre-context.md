## 9. For /speckit.specify

### Summary
F005-assistant manages assistant CRUD, preset marketplace/import, agent management (Drizzle DB), quick phrases, and the assistant list UI in the chat sidebar. Assistants encapsulate system prompts, model preferences, and topic collections.

### Scenarios
1. User creates new assistant -> default settings applied, appears in list
2. User imports preset -> preset becomes editable assistant
3. User edits assistant settings -> model/prompt/params updated
4. User deletes assistant -> removed from list with topic cleanup
5. User manages quick phrases -> phrases available in chat input
6. User reorders assistants via drag -> order persists

### Draft Functional Requirements
- **FR-033**: Assistant CRUD (create, read, update, delete)
- **FR-034**: Default assistant with pre-configured settings
- **FR-035**: Assistant presets marketplace with categories/search
- **FR-036**: Preset import as editable assistant
- **FR-037**: Agent management with Drizzle ORM persistence
- **FR-038**: Quick phrase management (CRUD)
- **FR-039**: Assistant tag grouping with collapsible sections
- **FR-040**: Unified assistant/agent list ordering

### Draft Scenarios
- **SC-014**: Given assistant list, when user clicks "+", then new assistant created with defaults
- **SC-015**: Given presets page, when user clicks preset card, then preset imported as assistant
- **SC-016**: Given assistant selected, when user edits settings, then changes persist

### Edge Cases
- Default assistant cannot be deleted
- Topic migration when assistant settings change
- Concurrent assistant modifications (multi-window)
- Preset compatibility across versions
