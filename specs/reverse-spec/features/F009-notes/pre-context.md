## 1. Runtime Exploration Results

**Screen**: `#/notes`

**Layout**: Navbar ("Notes" title) + collapsible left sidebar (folder tree with notes, animated show/hide) + editor area (header navbar + rich text/source/read mode editor + bottom panel)

### UI Elements
- Sidebar: Folder tree with file/folder nodes, drag-and-drop reorder, star toggle, expand/collapse folders, context menu (rename, delete, new note, new folder, upload)
- Sidebar header: Sort options (A-Z, Z-A, date), New Note button, New Folder button, Upload button
- Editor header navbar: Breadcrumb path, star toggle for current note, rename
- Editor area: TipTap rich text editor (preview mode) or Monaco CodeEditor (source mode) or read-only view
- Bottom panel: Character count, spell check toggle, view mode selector (Preview/Source/Read)
- Settings: Full width toggle, font family (default/serif), font size, table of contents, default view/edit mode, tab status, workspace visibility

### User Flows
| Flow | Steps | Observations |
|------|-------|--------------|
| Create note | Click New Note -> Enter name -> Note created in target folder | File created on disk as .md, tree refreshed |
| Create folder | Click New Folder -> Enter name -> Folder created | Folder expanded after creation |
| Edit note | Select note -> Type in editor -> Auto-saves (800ms debounce) | Content saved to filesystem |
| Switch view mode | Click Preview/Source/Read in bottom panel | TipTap (preview/read) or Monaco (source) |
| Star note/folder | Click star icon on node | Stored in Redux starredPaths[] |
| Move note | Drag node to folder or between nodes | File moved on disk, paths updated |
| Rename note | Right-click -> Rename or inline rename | File renamed on disk, active path updated |
| Delete note | Right-click -> Delete -> Confirm | File deleted via trash, tree refreshed |
| Upload files | Click Upload -> Select .md files | Files copied to target folder |
| Search notes | Full-text search across note files | Uses ripgrep or in-memory search |
| Sort notes | Click sort option (A-Z, Z-A, date) | Tree re-sorted, state persisted |
| Toggle sidebar | Click workspace toggle | Animated sidebar show/hide (250px width) |
| Locate line | External event -> Switch to note + scroll to line | Cross-note navigation support |

### Runtime Behavior
- Notes stored as .md files on disk (not in DB), using filesystem as source of truth
- File watcher (chokidar) monitors notes directory for external changes
- Tree state (expanded, starred) persisted in Redux, merged with filesystem tree
- Debounced auto-save at 800ms after last keystroke
- Emergency save on unmount/file switch to prevent data loss
- Cross-platform path normalization for backup restore scenarios
- Token/character count updated on content change

## 14. For /speckit.analyze

- Debounced save uses capture pattern for activeFilePath to avoid race conditions with file switching
- isRenamingRef and isCreatingNoteRef prevent false activeFilePath clearing during async operations
- normalizePathValue ensures consistent path comparison across platforms
- Tree state is not stored in filesystem -- starred/expanded state is Redux-only
- File watcher debounce (1000ms in FileStorage) prevents event flooding
- Emergency save pattern: save on both unmount and effect cleanup
- Scroll-to-line support requires double requestAnimationFrame for DOM readiness
