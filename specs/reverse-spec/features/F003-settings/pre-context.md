## 9. For /speckit.specify

### Summary
F003-settings provides all settings pages: provider configuration (API keys, endpoints), model management, display settings, general settings (language, proxy, launch), shortcuts, MCP/web search/memory config, data management, and about page. Settings state is a Redux slice with 50+ properties persisted via Dexie.

### Scenarios
1. User opens settings -> lands on provider settings
2. User configures AI provider -> enters API key, selects models
3. User changes theme/font/display settings -> instant preview
4. User configures shortcuts -> global shortcut registration updates
5. User manages data (backup/restore/export)
6. User configures proxy settings -> applies to all network requests

### Draft Functional Requirements
- **FR-018**: Settings page with sidebar navigation and 16 settings sub-pages
- **FR-019**: Provider configuration (API key, endpoint, models per provider)
- **FR-020**: Display settings (theme colors, font, font size, message style)
- **FR-021**: General settings (language, proxy, launch on boot, tray behavior)
- **FR-022**: Shortcut settings with customizable key bindings
- **FR-023**: Data management (backup to file/WebDAV/S3, restore, reset)
- **FR-024**: MCP server configuration
- **FR-025**: Web search provider configuration

### Draft Scenarios
- **SC-008**: Given settings open, when user enters API key for provider, then key is persisted
- **SC-009**: Given settings open, when user changes language, then UI re-renders in new language
- **SC-010**: Given settings open, when user changes proxy, then all network requests use new proxy

### Edge Cases
- Provider API key validation
- Data path migration (changing app data directory)
- Backup format compatibility across versions
- Shortcut conflicts with system shortcuts

## 10. For /speckit.plan

### Dependencies
- **F001**: ConfigManager for main-process config persistence, IPC for settings changes

### Platform Constraints
- Some settings are platform-specific (launch on boot behavior, tray, window controls)
- Proxy settings require main process IPC
- Shortcut settings require main process globalShortcut registration

### Entities Owned
- **Settings**: Full SettingsState shape (50+ properties) in Dexie/Redux
- **Provider**: `{ id, name, type, apiKey, apiHost, models, enabled, ... }`
- **Model**: `{ id, name, provider, type, capabilities, ... }`

### APIs
- Renderer: Redux settings slice actions
- Main: ConfigManager get/set/subscribe
- IPC: `App_Proxy`, `App_SetLaunchOnBoot`, `App_SetTheme`, `Shortcuts_Update`, etc.

### Tech Decisions
- [New Stack] Redux slice -> Zustand 5 store
- [New Stack] Ant Design form components -> shadcn/ui form components
- [New Stack] styled-components -> Tailwind CSS 4
- [Keep] electron-store for main process persistence
- [Keep] Dexie for renderer-side settings persistence
