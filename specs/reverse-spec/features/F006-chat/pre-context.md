## 9. For /speckit.specify

### Summary
F006-chat is the primary interface: chat messages display with streaming, input toolbar with 9+ configurable action tools, topic/assistant management panels, model selection, message operations (copy/edit/delete/regenerate), file attachments, web search, knowledge base, MCP tool integration, and markdown rendering.

### Scenarios
1. User types message and presses Enter -> message sent, response streams
2. User switches topic -> message list reloads
3. User attaches file -> file preview in input, included in message
4. User enables web search -> search results integrated in response
5. User toggles MCP -> tools available in AI response
6. User edits previous message -> message updated, response regenerated
7. User creates new topic -> clean conversation
8. User searches messages -> content search highlights matches

### Draft Functional Requirements
- **FR-041**: Chat message display with streaming support
- **FR-042**: Input toolbar with 9+ configurable action tools
- **FR-043**: Topic management (create, switch, delete, rename)
- **FR-044**: File attachment support (documents, images)
- **FR-045**: Web search integration toggle
- **FR-046**: Knowledge base selection and context injection
- **FR-047**: MCP tool integration (Disabled/Auto/Manual modes)
- **FR-048**: Message operations (copy, edit, delete, regenerate, translate)
- **FR-049**: Model selection per conversation
- **FR-050**: Markdown rendering with code highlighting
- **FR-051**: In-chat content search (Cmd+F)
- **FR-052**: Message block architecture (text, code, tool, citation blocks)
- **FR-053**: Multi-select mode for batch message operations
- **FR-054**: Assistant/Topics panel with animated show/hide

### Draft Scenarios
- **SC-017**: Given chat open, when user sends message, then response streams token by token
- **SC-018**: Given topic active, when user clicks new topic, then clean conversation starts
- **SC-019**: Given file attached, when message sent, then file context included in prompt
- **SC-020**: Given MCP Auto mode, when AI needs tool, then tool call executed automatically

### Edge Cases
- Long message rendering performance
- Concurrent streaming responses
- Large file attachment handling
- Network interruption during streaming
- Message block rendering for different types (text, code, tool results, citations)
- Topic pagination (displayCount: 10, load more on scroll)
- Model generating guard on navigation (prevents data loss)
