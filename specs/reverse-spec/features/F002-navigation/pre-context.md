## 9. For /speckit.specify

### Summary
F002-navigation provides the sidebar icon navigation, HashRouter routing with 13 routes, theme toggle, custom window controls (Win/Linux), and layout switching between left-sidebar and top-tabs modes.

### Scenarios
1. User clicks sidebar icon -> navigates to corresponding route
2. User toggles theme -> cycles through dark/light/system
3. User clicks avatar -> opens profile popup
4. Active route -> sidebar icon highlighted with primary color
5. Layout mode switch -> sidebar vs tabs layout
6. Window controls -> minimize/maximize/close on Win/Linux

### Draft Functional Requirements
- **FR-011**: Sidebar with configurable icon set (visibility controlled by settings)
- **FR-012**: HashRouter with 13 routes mapping to page components
- **FR-013**: Theme toggle cycling (dark/light/system) with icon change
- **FR-014**: Active route indication via icon styling
- **FR-015**: Custom window controls for Windows and Linux (frameless mode)
- **FR-016**: Layout mode switching (left sidebar vs top tabs)
- **FR-017**: Model generating guard before navigation (prevents nav during streaming)

### Draft Scenarios
- **SC-005**: Given sidebar visible, when user clicks chat icon, then navigates to `/` with icon highlighted
- **SC-006**: Given dark theme, when user clicks theme toggle, then switches to light theme
- **SC-007**: Given model is generating, when user clicks nav icon, then waits for generation to complete

### Edge Cases
- Fullscreen mode adjusts sidebar height (macOS titlebar-area-height)
- Minapp popup z-index management when open
- Window controls hidden on macOS (native traffic lights used)
- Linux system title bar option hides custom controls
