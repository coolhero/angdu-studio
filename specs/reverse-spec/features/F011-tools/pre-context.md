## 1. Runtime Exploration Results

**Screens**: `#/translate`, `#/paintings`, `#/code`, `#/apps`, `#/launchpad`

### Translate (`#/translate`)
**Layout**: Navbar ("Translate" title) + operation bar (language selects, translate button, model select, settings) + two-pane area (input textarea + output display)

- Operation bar: History button, source language selector (with auto-detect), swap button, target language selector, translate button (Send icon), model selector, settings button
- Input pane: TextArea with clear, file upload float button, drag-drop support, paste support (including OCR for images), token count
- Output pane: Read-only display with copy button (auto-hide), markdown rendering option
- Translate settings drawer: Scroll sync, bidirectional mode, markdown rendering, auto-copy, detection method (franc), prompt template
- History drawer: List of past translations, click to restore

### Paintings (`#/paintings`)
**Layout**: Navbar + provider-specific painting pages with route switching

- Provider routing: zhipu, aihubmix, silicon, dmxapi, tokenflux, ovms, ppio, new-api (generic)
- Each provider page: Image generation form (prompt, size, style, model), generation history, image gallery
- Provider options: System providers + custom new-api providers filtered dynamically
- OVMS provider: Checked for running status before showing
- Paintings state: Per-provider array of PaintingAction records with files

### Code Tools (`#/code`)
**Layout**: Navbar ("Code" title) + centered form

- CLI tool selector: Claude Code, Gemini CLI, OpenAI Codex, GitHub Copilot CLI, Qwen Code, iFlow CLI, Open Code
- Model selector: Filtered by CLI tool compatibility (Anthropic for Claude, OpenAI for Codex, etc.)
- Working directory: Folder selector with history, remove individual directories
- Environment variables: Text area for KEY=VALUE pairs
- Terminal selector: Platform-specific (macOS/Windows), with custom path for some terminals
- Auto-update checkbox
- Launch button: Validates bun installed, model selected, generates env vars, calls window.api.codeTools.run()
- Bun install alert: Warning banner if bun not installed, with install button

### Mini Apps (`#/apps`)
**Layout**: Navbar ("Mini Apps" title + search + settings) + grid of app icons

- App grid: Grid of MinApp icons (90px cells), searchable by name/URL
- New app button: Add custom web-based mini app
- Settings: MinappSettingsPopup for configuration
- Each app: Opens in embedded webview or external browser

### Launchpad (`#/launchpad`)
**Layout**: Centered grid of built-in feature icons + pinned/opened mini apps

- Feature grid: 9 items (Apps, Knowledge, Paintings, Store, Translate, Files, Code, OpenClaw, Notes) with colored gradient icon backgrounds
- Mini apps section: Pinned apps + opened keep-alive apps
- Navigation: Click icon navigates to feature route
- Scale animation on hover/click

## 14. For /speckit.analyze

- Translate uses module-level cache variables (_sourceLanguage, _targetLanguage) -- potential stale state issue
- Translate auto-copy uses setTimeout to avoid clipboard race conditions
- Paintings state uses string-keyed namespaces -- could be simplified with Map in Zustand
- Code tools model filtering varies by CLI tool -- complex predicate logic per tool type
- Code tools terminal detection is platform-specific (macOS and Windows only, not Linux)
- Launchpad features list is hardcoded -- consider making it dynamic from route config
- Mini app grid calculates container height from item count -- fragile layout calculation
- Token estimation uses estimateTextTokens which includes the prompt template in count
