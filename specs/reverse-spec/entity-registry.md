## 1. Assistant

**Owner**: F003 chat-core
**Storage**: Zustand store (persisted to IndexedDB)

### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | string | yes | UUID |
| name | string | yes | Display name |
| prompt | string | yes | System prompt |
| type | string | yes | Assistant type identifier |
| emoji | string | no | Avatar emoji |
| description | string | no | Short description |
| model | Model | no | Default model override |
| defaultModel | Model | no | Fallback model |
| settings | Partial\<AssistantSettings\> | no | Temperature, maxTokens, contextCount, etc. |
| messages | AssistantMessage[] | no | Preset conversation messages (role + content) |
| topics | Topic[] | yes | Conversation topics |
| knowledge_bases | KnowledgeBase[] | no | Attached knowledge bases |
| enableWebSearch | boolean | no | Use model's built-in web search |
| webSearchProviderId | string | no | External web search provider |
| enableUrlContext | boolean | no | Gemini/Anthropic URL context |
| enableGenerateImage | boolean | no | Allow image generation |
| mcpMode | 'disabled' \| 'auto' \| 'manual' | no | MCP tool mode |
| mcpServers | MCPServer[] | no | Manually selected MCP servers |
| knowledgeRecognition | 'off' \| 'on' | no | Knowledge base auto-recognition |
| regularPhrases | QuickPhrase[] | no | Quick phrases for this assistant |
| tags | string[] | no | Category tags |
| enableMemory | boolean | no | Enable memory injection |
| content | string | no | For translate assistant |
| targetLanguage | TranslateLanguage | no | For translate assistant |

### Relationships

- **has many** Topic (via `topics` array)
- **has one** Model (optional, via `model`)
- **has many** MCPServer (optional, via `mcpServers`)
- **has many** KnowledgeBase (optional, via `knowledge_bases`)

### Validation Rules

- `id` must be non-empty UUID
- `name` must be non-empty string
- `prompt` can be empty string but must exist
- `mcpMode` defaults to 'disabled' when absent (backward compat: if `mcpServers` present, defaults to 'manual')
