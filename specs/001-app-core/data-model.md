## Entity Definitions

### 1. AppConfig (electron-store schema)

The root configuration object persisted by `electron-store` to `config.json` in the app data directory. Each field corresponds to a `ConfigKeys` enum member.

```typescript
/** Typed schema for electron-store. All fields are optional with defaults. */
interface AppConfigSchema {
  // Identity
  clientId: string;                   // UUID v4, generated on first launch

  // Appearance
  theme: ThemeMode;                   // default: 'system'
  zoomFactor: number;                 // default: 1.0, range: 0.5–3.0

  // Language
  language: string;                   // BCP 47 tag, default: 'ko' (Korean)

  // Proxy
  proxyMode: ProxyMode;              // default: 'system'
  proxyUrl: string;                   // e.g. 'socks5://127.0.0.1:1080' or 'http://proxy.corp:8080'
  proxyBypassRules: string;           // semicolon-separated, e.g. '<local>;*.example.com;192.168.0.0/16'

  // System tray
  tray: boolean;                      // default: true
  trayOnClose: boolean;               // default: true (minimize to tray on close)
  launchToTray: boolean;              // default: false

  // Updates
  autoUpdate: boolean;                // default: true
  updateChannel: UpdateChannel;       // default: 'latest'

  // Shortcuts
  shortcuts: ShortcutBinding[];       // default: ZOOM_SHORTCUTS (Ctrl+=/Ctrl+-/Ctrl+0)

  // Quick assistant
  enableQuickAssistant: boolean;      // default: false
  clickTrayToShowQuickAssistant: boolean; // default: false

  // Advanced
  disableHardwareAcceleration: boolean; // default: false
  useSystemTitleBar: boolean;           // default: false
  enableDeveloperMode: boolean;         // default: false
}
```

### 4. ProxyMode Type

```typescript
export type ProxyMode = 'system' | 'custom' | 'none';
```

- `'system'` — detect OS proxy via `os-proxy-config`, poll every 60s
- `'custom'` — use `proxyUrl` and `proxyBypassRules` from config
- `'none'` — direct connection, clear all proxy env vars

### 5. ProxyConfig

```typescript
/** Runtime proxy configuration passed to ProxyManager.configureProxy() */
export interface ProxyConfig {
  mode: ProxyMode;
  url?: string;                // proxy URL (http, https, socks4, socks5)
  bypassRules?: string[];      // parsed bypass rule strings
}

/** Parsed proxy bypass rule (internal to ProxyManager) */
export interface ParsedProxyBypassRule {
  type: 'local' | 'cidr' | 'ip' | 'domain';
  matchType: 'exact' | 'wildcardSubdomain' | 'generalWildcard';
  rule: string;               // original rule string
  scheme?: string;             // protocol filter (http, https)
  port?: string;               // port filter
  domain?: string;             // for domain rules
  regex?: RegExp;              // for wildcard rules
  cidr?: [IPv4 | IPv6, number]; // for CIDR rules (ipaddr.js)
  ip?: string;                 // for exact IP rules
}
```

### 6. AppNotification (runtime, in-memory)

```typescript
/** Ephemeral notification object — never persisted to disk */
export interface AppNotification {

  type: 'info' | 'warning' | 'error' | 'success';
  title: string;                      // i18n key or plain text
  message: string;                    // i18n key or plain text
  source: string;                     // originating service (e.g. 'update', 'proxy', 'mcp')
  progress?: number;                  // 0–100, for download/import progress
  actions?: NotificationAction[];     // clickable buttons

}
```

## Data Flow Summary

```
┌─────────────────────────────────────────────────┐
│                  electron-store                  │
│              (config.json on disk)               │
│                                                  │
│  ConfigKeys → AppConfigSchema fields             │
│  Managed by: ConfigManager (singleton)           │
│  Access: main process only, renderer via IPC     │
└──────────────────────┬──────────────────────────┘
                       │
         ConfigManager.subscribe(key, cb)
                       │
         ┌─────────────▼─────────────┐
         │     Main Process Services  │
         │  ThemeService              │
         │  ProxyManager              │
         │  TrayService               │
         │  ShortcutService           │
         │  UpdateService             │
         │  NotificationService       │
         └─────────────┬─────────────┘
                       │
              IPC (webContents.send)
              StoreSync_Push channel
                       │
         ┌─────────────▼─────────────┐
         │    Renderer (Zustand)      │
         │  useAppStore               │
         │  useThemeStore             │
         │  useNotificationStore      │
         └───────────────────────────┘
```

- **electron-store** persists config on disk (main process)
- **electron-window-state** persists window geometry separately
- **Zustand stores** hold renderer-side state (hydrated from main on init)
- **AppNotification** is ephemeral — lives only in memory, pushed via IPC
- **ProxyConfig** runtime state is in-memory in `ProxyManager`
