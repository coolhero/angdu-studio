# Translate — Spec Draft

> `/reverse-spec` Phase 4에서 자동 생성. `/speckit.specify`의 시드 입력으로 사용.

## Feature 설명

LLM 기반 번역 기능을 제공하는 독립 페이지이다. 좌측 입력 + 우측 출력의 분할 패널 레이아웃으로, 언어 자동 감지, OCR 이미지 텍스트 추출, 번역 이력 관리, 스트리밍 응답을 지원한다.

## 성공 기준 (Success Criteria)

### Happy Path
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-001 | 텍스트 번역 | 한국어 텍스트 입력 → Send | Auto Detect로 한국어 감지 → 영어로 스트리밍 번역 |
| SC-002 | 언어 교환 | 번역 완료 후 Swap 버튼 클릭 | 소스↔대상 언어 교환, 양방향 모드면 텍스트도 교환 |
| SC-003 | 이미지 OCR 번역 | 이미지 파일 드래그 앤 드롭 | OCR로 텍스트 추출 → 입력 영역에 채움 → 번역 가능 |
| SC-004 | 번역 이력 복원 | 이력 드로어에서 과거 항목 클릭 | 해당 번역의 입출력이 복원됨 |
| SC-005 | 자동 복사 | autoCopy 활성 상태에서 번역 완료 | 결과가 클립보드에 자동 복사됨 |

### Error Paths
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-E01 | 번역 API 실패 | 잘못된 모델/API Key | 에러 메시지 표시, 입력 텍스트 유지 |
| SC-E02 | OCR 실패 | PaddleOCR 바이너리 없음 | 에러 토스트, 수동 텍스트 입력으로 안내 |
| SC-E03 | 빈 입력 번역 | 텍스트 없이 Send | 전송 무시 |
