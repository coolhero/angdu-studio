# Implementation Plan: Chat UI

**Branch**: `005-chat-ui` | **Date**: 2026-03-09 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/005-chat-ui/spec.md`

## Summary

Complete chat user interface for Angdu Studio: TipTap-based rich input bar with 18 tools via registry pattern, react-markdown rendering pipeline with Shiki syntax highlighting / KaTeX math / Mermaid diagrams, real-time streaming display with block-level status tracking and smooth animation, per-message action toolbar, sidebar navigation (assistants/topics/sessions), infinite scroll with lazy loading, content search, and responsive layout. Migrates from Ant Design + styled-components to shadcn/ui + Tailwind CSS 4, and from Redux to Zustand for 3 new UI-specific stores.

## Technical Context

**Language/Version**: TypeScript 5.8, targeting ES2022
**Primary Dependencies**: React 19, Electron 40, shadcn/ui, Tailwind CSS 4, TipTap 3, react-markdown, Shiki, KaTeX, Mermaid, @xyflow/react, @hello-pangea/dnd, react-infinite-scroll-component, react-hotkeys-hook, motion/react, Sonner, lucide-react, i18next
**Storage**: Dexie (IndexedDB) for messages/blocks/topics (F003), electron-store for settings (via IPC), Zustand persist for UI preferences
**Testing**: Vitest for unit tests, Playwright for E2E
**Target Platform**: Electron 40 (macOS, Windows, Linux)
**Project Type**: Desktop app (Electron)
**Performance Goals**: 60fps scroll during streaming, <200ms first token render, <100ms tool response
**Constraints**: No direct Node.js in renderer (IPC bridge), i18n (ko + en), all text via i18next keys
**Scale/Scope**: ~70 components, 3 new stores, 15+ hooks, 18 input tools, 11 block renderers

## Implementation Phases

### Phase 1: Foundation — Stores, Services, Hooks, UI Primitives

Install new dependencies (shadcn/ui components, Sonner, TipTap, react-markdown, Shiki, etc.). Create 3 Zustand stores (useRuntimeStore, useSettingsStore, useInputToolsStore). Create EventService with typed ChatEvent enum. Implement core hooks (useSmoothStream, useSettings, useRuntime, useShortcut, useConfirmDialog, useTimer). Set up ConfirmDialogProvider and Sonner ToastProvider in App.tsx. Add shadcn/ui components to `components/ui/`.

**FR coverage**: FR-027 (draft caching via useInputText), FR-032 (generation state guard via useRuntimeStore.generatingTopicIds)
**Deliverables**: 3 stores, EventService, 8 hooks, UI providers, dependencies installed
**Tests**: Store unit tests, hook unit tests, EventService tests

### Phase 2: Markdown Rendering Pipeline

Implement the Markdown component with react-markdown, remark-gfm, remark-math, rehype-katex, rehype-mathjax, rehype-raw, and 3 custom plugins (rehypeHeadingIds, rehypeScalableSvg, remarkDisableConstructs). Implement CodeBlock with Shiki highlighting (theme-aware via useThemeStore). Implement Table with horizontal scroll, Link with external handling, CitationTooltip, and MarkdownSvgRenderer. Integrate Mermaid for diagram rendering. Wire useSmoothStream into Markdown for streaming animation.

**FR coverage**: FR-004, FR-005, FR-006, FR-007, FR-008, FR-037
**Deliverables**: Markdown component, CodeBlock, Table, Link, CitationTooltip, MarkdownSvgRenderer, 3 remark/rehype plugins
**Tests**: Markdown rendering tests (code, math, tables, Mermaid, SVG, streaming)

### Phase 3: Message Block Renderers

Implement MessageBlockRenderer dispatch component that maps MessageBlock.type to specific components. Implement all 11 block type components: MainTextBlock (uses Markdown), ThinkingBlock (collapsible + elapsed time), ToolBlock/ToolBlockGroup (formatted arguments/output), ImageBlock (lightbox), VideoBlock, FileBlock, CitationBlock (source links + tooltips), ErrorBlock (serialized details), TranslationBlock, CompactBlock, PlaceholderBlock (loading). Implement UnknownBlock fallback for unrecognized types. Add motion/react animation wrappers for block entrance.

**FR coverage**: FR-009, FR-010, FR-011, FR-012, FR-013, FR-014, FR-015, FR-019, FR-038
**Deliverables**: 12 block components + MessageBlockRenderer
**Tests**: Block renderer tests for each type, unknown type fallback test

### Phase 4: Message List and Actions

Implement Messages component with react-infinite-scroll-component (reverse scroll, lazy loading). Implement Message component (header, content, editor, menubar). Implement MessageGroup for askId-based grouping. Implement MessageHeader (avatar, model, timestamp), MessageContent (thin wrapper to BlockRenderer), MessageMenubar (hover toolbar with copy/edit/retry/delete/translate/fork/TTS/bookmark actions). Implement MessageEditor for inline editing with save/resend. Implement Prompt for system prompt display. Implement ChatNavigation (scroll-to-bottom, jump-to-message). Implement NarrowLayout responsive wrapper. Implement useMessageOperations, useTopicMessages, useTopicLoading, useScrollPosition hooks.

**FR coverage**: FR-016, FR-017, FR-018, FR-021, FR-022, FR-023, FR-025, FR-026, FR-029, FR-031, FR-035, FR-036, FR-039
**Deliverables**: Messages, Message, MessageGroup, MessageHeader, MessageContent, MessageMenubar, MessageEditor, Prompt, ChatNavigation, NarrowLayout, SelectionBox, 4 hooks
**Tests**: MessageMenubar action tests, infinite scroll loading test

### Phase 5: Input Bar and Tool Registry

Implement the input tool registry (defineTool/registerTool) with ToolDefinition type. Implement InputbarToolsProvider context. Implement Inputbar with TipTap editor, draft caching (useInputText with 24h TTL), file attachment preview, token count display, and send button with configurable shortcut. Implement InputbarTools toolbar with DnD ordering via @hello-pangea/dnd. Implement SendMessageButton with send/stop states. Implement TokenCount for real-time token estimation. Implement AttachmentPreview. Implement RichEditor wrapper for TipTap. Implement QuickPanel for slash commands and mentions. Implement all 18 input tools as individual modules.

**FR coverage**: FR-001, FR-002, FR-003, FR-028, FR-033
**Deliverables**: Inputbar, InputbarCore, InputbarTools, 18 tool modules, RichEditor, QuickPanel, AttachmentPreview, TokenCount, SendMessageButton, registry
**Tests**: Tool registry tests, input text draft caching test

Implement MessageMcpTool component for MCP tool call display (arguments table, response, progress). Implement ToolApprovalActions for approve/deny UI. Implement shared tool UI components (ArgsTable, truncateOutput). Wire tool approval workflow into the message rendering pipeline.

**FR coverage**: FR-012, FR-020
