# Memory — Spec Draft

> `/reverse-spec` Phase 4에서 자동 생성. `/speckit.specify`의 시드 입력으로 사용.

## Feature 설명

시맨틱 메모리 시스템으로, 대화에서 자동으로 중요한 정보를 추출하여 벡터 임베딩과 함께 LibSQL DB에 저장한다. 해시 기반 중복 방지, 유사도 기반 자동 병합, 소프트 삭제/복원, 하이브리드 검색을 지원하며, 채팅 시 AI Tool로 관련 메모리를 컨텍스트에 주입한다.

## 성공 기준 (Success Criteria)

### Happy Path
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-001 | 메모리 자동 추출 | 대화 완료 후 | 어시스턴트 응답에서 중요 정보를 추출하여 벡터 임베딩과 함께 저장 |
| SC-002 | 메모리 검색 주입 | 새 메시지 전송 시 | 관련 메모리를 하이브리드 검색으로 찾아 AI Tool로 컨텍스트 주입 |
| SC-003 | 중복 방지 | 동일 내용 재추가 시도 | SHA-256 해시 일치 → 기존 메모리 유지, 중복 저장 안 됨 |
| SC-004 | 삭제 복원 | 삭제된 메모리와 동일 해시로 재추가 | is_deleted → 0으로 복원, 새로 생성하지 않음 |
| SC-005 | 설정 변경 | 임베딩 모델 변경 | MemoryService.reload() → 새 모델로 재초기화 |

### Error Paths
| ID | 시나리오 | 조건 | 기대 결과 |
|----|---------|------|----------|
| SC-E01 | 임베딩 API 실패 | 임베딩 모델 미설정 | 메모리 추가 실패, 에러 로깅 |
| SC-E02 | DB 초기화 실패 | LibSQL 파일 접근 불가 | 메모리 기능 비활성화, 에러 알림 |
| SC-E03 | 벡터 인덱스 미지원 | 구 버전 LibSQL | 폴백 검색으로 동작, 성능 저하 경고 |
